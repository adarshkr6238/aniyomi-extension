# Aniyomi Extension (Universal + AnimePahe)

Custom Aniyomi extension featuring AnimePahe and a **Universal Link** player.

## 📥 Repository Link (Add to Aniyomi)

Add this URL to **Settings > Browse > Anime extension repos**:

```
https://adarshkr6238.github.io/aniyomi-extension/index.min.json
```

## 🚀 Key Features

- **Universal Link Player**: Paste **ANY** anime streaming site URL into the search bar, and the extension will try to play it using 48+ built-in extractors.
- **Custom Domains**: Change AnimePahe mirror in settings (e.g., .org, .com).
- **Quality Control**: Support for 2160p, 1080p, 720p, 480p, 360p.
- **AdBlocker**: Built-in popup and ad blocking for webview-based bypasses.

## 🛠️ How to use Universal Player

1. Open **Universal Paste Link** source in Aniyomi.
2. Tap the **Search** icon.
3. **Paste the full URL** of an anime episode page (e.g., from GogoAnime, Zoro, etc.).
4. Extension will automatically find the video stream.
