## 🚀 Features

- **Custom Domains**: Input any valid mirror/domain in settings.
- **Quality Control**: Select preferred resolution (2160p, 1080p, 720p, 480p, 360p).
- **AdBlocker**: Built-in popup and ad blocking for Cloudflare bypass screens.
- **AV1 Support**: Toggle AV1 codec preference.
